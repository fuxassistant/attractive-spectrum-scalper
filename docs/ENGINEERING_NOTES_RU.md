# Решения и найденные ограничения

1. Сырьё уже находилось в новом репозитории. Старые абсолютные пути в его manifests указывают на предыдущий checkout; raw bytes не изменялись, текущие пути и SHA фиксируются заново.
2. Для двух недель выбран route (1,19181,22) по числу записей первого префикса; разные инструменты не объединяются. Дневные source resets дают 12 независимых частей, включая короткие воскресные открытия.
3. Первое измерение включало неправильный малоликвидный route 4782 и потому не использовалось как benchmark рабочего инструмента. Основной профиль переснят на 19181.
4. На первом probe feature-lab ошибочно распространяла свежесть каждого исторического endpoint на всё FFT-окно. Из-за этого поддержка 128s искусственно падала. Исправление: historical support отдельно от current-origin admission; текущий false admission по-прежнему запрещает использование выходной строки. Probe сохранён в `.tmp/feature_probe`, исправленный — `.tmp/feature_probe_v2`; в основной генерации используется исправленная версия.
5. Первые 38 migrated tests прошли, но глобальная pytest atexit cleanup встретила чужой недоступный временный symlink. Финальные тесты используют явный workspace `--basetemp`; существующие чужие временные каталоги не удалялись.
6. Calendar-v1 ограничен исследуемым маем. Наличие cTrader-пропуска не доказывает пропуск GC; эти источники проверяются раздельно.
7. Raw reconstruction остаётся последовательной внутри одного инструмента. Ускорение повторных экспериментов даёт материализация рыночного слоя, columnar decode, bounded native FFT/Arrow kernels и независимые процессы. Измерение decoder speedup не выдаётся за такое же ускорение всей реконструкции.
8. `spectrum/core` сохраняет проверенное исходное ядро; старые вспомогательные модули внутри него не являются активным календарём или policy нового проекта. Public API нового маршрута — `spectrum.replay`, `spectrum.tape`, `spectrum.lab`, `spectrum.calendar`.
9. Во время независимых capture jobs публичный wrapper получил защиту cutoff для iterator (требуется indexable batch) и делегирующие advance/gap/finish методы. Generation вызывает прежний feed без cutoff, его путь не менялся. Исходные fingerprints запуска сохранены отдельно; ядро реконструкции и формат результатов не изменялись.
10. Sol 6.1 нашёл визуальный дефект первого атласа: line plot BBO соединял последнюю и следующую публикации через часовой перерыв. Данные/маски не менялись; renderer теперь маскирует closed-calendar quotes и разрывает линию при промежутке >30 секунд. `reports/audit_v1` — superseded, финальная повторная визуальная приёмка относится к `reports/audit_v2`.
