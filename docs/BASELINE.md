# Бейслайн 0.3.0 перед обучением — 27 октября 2026

Ветка: `codex/baseline-0.3.0`. Аннотированный тег: `baseline-0.3.0`.
Код библиотеки взят из `5439815`: все 106 Python/JSON файлов runtime сохранены
побайтно, включая 22 файла исходного MBO core. Бейслайн добавляет окружение,
идентичности данных, проверки восстановления и документацию. Он не допускает
данные к обучению и не заявляет торговую доходность.

## Зафиксированное окружение

CPython **3.12.14 x86_64**, пакет `attractive-spectrum-scalper==0.3.0`,
20 точных зависимостей вместе с инструментами сборки и тестирования.
Два lock-файла в `requirements/` задают версии и SHA-256 конкретных wheels
для Windows и Linux x86_64. `pyproject.toml` ограничивает Python веткой 3.12,
а `.python-version` и проверка окружения требуют именно 3.12.14 для бейслайна.
Изменение версии Python или любой зависимости требует нового свидетельства
проверки. Внешние пакеты обучения в окружение не входят.

При подготовке обнаружен унаследованный `.venv` с CPython 3.12.14 и чужими
editable-зависимостями. Поэтому проверки выполнены в новых venv из сохранённого
интерпретатора. Утверждение старого VALIDATION о Python 3.11 не было подкреплено
записью интерпретатора и исправлено; Python 3.10.11 здесь не использовался.

Для установки на другой машине нужен CPython 3.12.14 x86_64 и подходящий lock.
Команды онлайн-установки приведены в README. Офлайн-восстановление Windows
из сохранённых локальных файлов, из корня checkout:

```powershell
# Сначала сверить SHA-256 архива с baselines/0.3.0/python-runtime.json.
Get-FileHash .tmp/baseline/cpython-3.12.14-windows-x86_64.zip -Algorithm SHA256
# Используйте новый каталог: существующее окружение не перезаписывается.
Expand-Archive .tmp/baseline/cpython-3.12.14-windows-x86_64.zip .tmp/restored-python
.tmp/restored-python/python.exe -m venv .tmp/restored-venv
$py = '.tmp/restored-venv/Scripts/python.exe'
& $py -m pip install --no-index --find-links .tmp/baseline/wheels-windows --require-hashes -r requirements/baseline-windows-py312.lock
& $py -m pip install --no-deps --no-build-isolation -e .
$env:PYTHONHASHSEED='0'
$env:OMP_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:NUMBA_NUM_THREADS='1'
& $py tools/baseline_environment.py --lock requirements/baseline-windows-py312.lock
& $py -m pip check
& $py -m pytest -q tests checks
```

`baselines/0.3.0/environment.json` фиксирует фактически проверенную Windows-среду.
`python-runtime.json` содержит реестр файлов интерпретатора и хеш ZIP;
`wheels-windows.json` и `wheels-linux.json` — хеши скачанных дистрибутивов.
Архив интерпретатора, wheels, собранный пакет и данные лежат **локально вне Git**.
Для долговременного восстановления необходимо сохранить их отдельной резервной
копией; публикация Git-ветки сама по себе этой копии не создаёт. Полный образ ОС,
драйверы, железо и состояние процессов не зафиксированы: побайтное восстановление
всей машины потребовало бы отдельного образа/VM. Совпадение версии Python между
локальной средой и CI также не означает совпадение его бинарной сборки.

## Паспорт данных

[`data-passport.json`](../baselines/0.3.0/data-passport.json) классифицирует каждый
набор. [`data-files.jsonl`](../baselines/0.3.0/data-files.jsonl) содержит относительный
путь, размер и SHA-256 **каждого из 14 824 файлов**, суммарно **66 793 476 649 байт**.
Хеши посчитаны по реальным локальным байтам `data/derived` и `data/legacy`.
Корневые `data/raw`, `data/labels`, `data/research` не включены; наличие внешних
архивов и возможность повторить весь replay этим паспортом не доказаны.

| Набор | Статус для этого бейслайна |
|---|---|
| `derived/bb_crossing_bank_v3` | Текущий фактический банк: 238 дней, 2025-10-01..2026-09-01, 8 956 654 события. Имя каталога V3, формат хранения **CROSSING_BANK_LIBRARY_V4**, геометрия **QUOTE_NATIVE_BID_OR_ASK_CLUSTER_V3** — разные версии, не противоречие |
| `derived/basket_multimonth_v1` | Исторический каталог источников банка; его производные представления не объявлены текущим X |
| `features_v1`, `features_v2`, `features_may_extension_v1`, `features_may_roll_v1` | Майские снимки; эквивалентность подтверждена только для восьми явно перечисленных capture |
| Соответствующие `market_*` | Зафиксированные исходные секундные tapes этих снимков |
| `derived/full_mbo_v1` | Историческая реконструкция, 291 capture receipt; многомесячные признаки **существуют**, но не сертифицированы относительно текущей реализации |
| Банки V1/V2 и `legacy/*` | Предыдущая геометрия/форматы, сохранены для истории |
| `finalized_*` | Пилот/частичный результат; исходные PARTIAL/BLOCKED/SUPERSEDED статусы не повышены до COMPLETE |
| Прочие исследовательские наборы | Архив исследований; не допущены как текущие X, target или обучающие данные |

Повторная полная проверка хешей (читает около 67 ГБ, ничего не меняет):

```powershell
python tools/baseline_data.py verify --data-root data
python tools/baseline_bank.py --data-root data --output .tmp/new-bank-compatibility.json
```

Для нового снимка используйте `inventory --output <новый-каталог>`; не затирайте
паспорт тега после новых экспериментов. Проверки в `checks/` сверяют внутреннюю
целостность записей без приватных данных, но не заменяют чтение payload-файлов.
`bank-compatibility.json` отдельно фиксирует сверку 238 дневных манифестов,
геометрии, 476 payload-файлов и числа строк. В текущем банке 61 948 `line_visit`
и 519 825 `opportunity`; кластерные маркеры не превращают факты в доходность.

## Сертификат признаков

[`feature-equivalence.json`](../baselines/0.3.0/feature-equivalence.json) связывает
старую реализацию `58fc768e…` / `OBSERVED_MAY_2026_V1` с текущей `707060c8…` /
`CANON_CALENDAR_V1`. Воспроизводимая команда:

```powershell
python tools/baseline_features.py --data-root data --output .tmp/new-feature-equivalence.json
```

Для каждой из восьми выборок пересчитаны и побайтно сравнены dtype и значения
всех **369 колонок**: 182 признака, их маски и пять служебных колонок.
Проверены units, исходный seconds payload, оба манифеста и хеш сохранённых признаков.
Выборка охватывает 3, 5, 10, 12, 17, 19, 24 и 26 мая 2026: воскресное открытие
и будний день каждого набора. Это равенство массивов колонок, а не вновь
созданных Parquet-файлов целиком.

Исторические манифесты **не переписаны**: сертификат сохраняет их исходное
происхождение. Он не распространяется автоматически на остальные capture,
другие сезоны, многомесячные признаки или другие семейства. Совпадение ожидаемо
для мая: 17:00 New York соответствует прежнему перерыву 21:00 UTC. Полный replay
MBO и пересчёт всей истории оставлены следующему этапу.

## Контракты и точка возврата

Текущие контракты выделены в `docs/MIGRATION.json:current_contracts`;
исторические переходы сохранены отдельно. Кластерные маркеры, кулдаун 8 секунд,
FutureFrame/Series/Array и FEATURE_STREAM_V3 отражены явно. Комиссия $0.30 и
кулдаун остаются предположениями канона; спред, задержка и timeout — defaults.
Ограниченный августовский `core.calendar.operational_gate` и полный календарь
праздников не входят в обещания этого бейслайна.

Для новой работы создайте ветку от `baseline-0.3.0`. Для просмотра исходного
состояния используйте `git switch --detach baseline-0.3.0` после сохранения
незакоммиченной работы. Исследовательский архив остаётся в
`codex/archive/research-2026-10-26`.

Локальные результаты записаны в [VALIDATION](VALIDATION.md) и
`baselines/0.3.0/validation.json`. Пуш ветки/тега и первый серверный CI требуют
отдельного согласия пользователя. До такого запуска статус remote CI —
**NOT_RUN**, включая Linux. Workflow подготовлен для Windows/Linux; скачанные
Linux wheels ещё не являются свидетельством успешного исполнения на Linux.
