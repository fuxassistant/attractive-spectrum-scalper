# Проверка корзинного мартингейла по месяцам

Этот эксперимент переносит замороженную августовскую конфигурацию на остальные доступные месяцы. Повторного поиска параметров нет. Каждый месяц получает отдельные $1500; внутри месяца капитал и непогашенная серия переходят между днями. Результаты независимых стартов нельзя складывать в одну непрерывную equity-кривую.

## Подготовка

```powershell
.venv/Scripts/python.exe -m spectrum.playground.multimonth --workers 3
.venv/Scripts/python.exe -m spectrum.playground.multimonth_evaluate
.venv/Scripts/python.exe -m spectrum.playground.multimonth_audit
.venv/Scripts/python.exe -m spectrum.playground.multimonth_report
```

Данные: `data/derived/basket_multimonth_v1`. Отчёт: `reports/basket_multimonth_v1/index.html`; для загрузки поминутных диапазонов нужен HTTP-сервер из этой директории.

Подготовка один раз сверяет SHA-256 исходных сжатых DBN members и канонических quotes/seconds/bars, проверяет Parquet footer и сохраняет ссылки на аудит идентичности каждой публикации. Заново реконструировать MBO не требуется. Исполнение читает существующие котировки; новая копия ленты не создаётся. Материализуются M1-входы, допустимые моменты решений, маски поддержки и границы сегментов. Это компактный `BASKET_M1_ONLY_V1`, не полный mixed-memory набор для нейросети. Прежний августовский mixed-memory набор остаётся доступен.

Работники независимы по дням. Они используют предыдущую календарную дату как часть текущей торговой сессии, включая границу месяца, и только выбранный контракт. Контракт и время доступности его выбора берутся из канонического manifest. Полностью опубликованные дни при возобновлении проверяются и переиспользуются. Неопубликованные частичные директории требуют разбора. Резерв свободного места — 10 GiB. В `progress.json` сохраняются причины ошибок.

`COMPLETE` означает готовность всех доступных дней, а не полноту календаря. В каждом месяце отдельно перечислены отсутствующие будни и исключённые исходные фрагменты. Это список покрытия, а не автоматическое заключение, что в такой день биржа работала или не работала. Отсутствие спотовой OHLC не заменяет факт состояния фьючерсного стакана. Сентябрь 2026 содержит только 1 сентября.

## Исполнение и риск

Входы и добавления разрешены с 08:00 Europe/London до 17:00 America/New_York с учётом DST. Предшествующие часы используются как контекст. Позиция закрывается перед концом дневной поддержки; серия при этом не обнуляется. Плановый перерыв, невалидный стакан, смена поддержки и просто молчание котировок различаются. Молчание само по себе не объявляется потерей поддержки.

Начальный вход — 1 oz; замороженный кандидат добавляет 1.5 и 2.25 oz. Комиссия $0.30/oz за полный оборот резервируется при входе. Исполнение использует фактический bid/ask после задержки 100 мс, а не midpoint. Гибель — потеря строго более 50% капитала на начало активной серии, включая открытую позицию. Остановка одной корзины не обнуляет накопленный убыток серии.

Потеря поддержки открытой позиции цензурирует результат. Последний известный equity такого прогона не считается месячным заработком. Модель не воспроизводит биржевую маржу GC, очередь заявок и влияние объёма на рынок. Это симуляция в унциях на котировках GC.

## Новый измеритель: min–max баланса и equity

`equity_envelope.json` сохраняет для каждой минуты минимум, максимум и последнее значение:

- **Баланс**: реализованный PnL и зарезервированная комиссия.
- **Equity**: баланс плюс стоимость немедленного закрытия всей открытой корзины по bid для LONG и ask для SHORT.

Диапазон строится по каждой опубликованной котировке во время экспозиции и по состояниям до/после исполнений. Экстремум между минутными закрытиями не теряется. При отсутствии позиции equity равна балансу. Внутри открытой позиции неизвестные значения не интерполируются. После цензурирования линия обрывается; последняя неполная минута помечается. Дневные диапазоны объединяют минутные. Это отчётная метрика, она не поступает в причинные входы политики.

График дополняет, а не заменяет максимальную просадку от исторического equity-пика и максимальную потерю относительно капитала начала серии: диапазон min–max сам по себе не содержит порядок экстремумов.

## Воспроизводимость

Проверяется неизменность численного ядра относительно августовского `frozen.json`. Протокол фиксирует рецепт, каталог данных и исходный код исполнения. Для каждого результата сохраняется `complete.json` с хешами manifest каждого входного дня, кода оценщика, кода диапазонов и отчётных файлов. Изменившийся завершённый результат не принимается молча. Независимый аудит сверяет каждую оценку открытой позиции, исполнение, комиссию, просадку и капитал начала серии. Дополнительно старый и новый август сравниваются по входным массивам и всем сделкам.

Август — данные выбора; остальные месяцы являются исторической проверкой переноса, а не гарантированно нетронутым blind test. Новая проверка может опровергнуть устойчивость августовского кандидата. Положительный отдельный месяц этого не отменяет.
