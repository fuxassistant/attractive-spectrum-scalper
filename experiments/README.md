# Пространство для новых опытов

Создавайте отдельный каталог на гипотезу: `experiments/<name>/` с коротким README,
конфигурацией и точкой запуска. Библиотека импортируется из `spectrum`.

В описании опыта укажите вопрос, источники, часы и доступность X, выбранные
семейства, будущие targets/units/masks/maturity, chronological splits и критерий
результата. Если проверяется торговое решение, отдельно задайте исполнение,
издержки и сравнение с WAIT/контролями.

Код и небольшой config можно коммитить. Датасеты, checkpoints и результаты
запуска сохраняются в `data/` и `research_results/<name>/<run>/`, которые
игнорируются Git. Для каждого запуска используйте новый каталог.

Завершённый опыт можно сохранить отдельной архивной веткой и убрать из активной.
Общие проверенные формулы сначала переносятся в библиотеку с тестами; библиотека
не должна импортировать experiments или файлы результатов.
